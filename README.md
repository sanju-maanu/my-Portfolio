# Portfolio Project

This repository contains a portfolio website. It includes HTML files and images organized in folders. You can deploy this site using GitHub Pages.

## Structure
- `Untitled-1.html`: Main HTML file
- `images/`: Contains image assets

## Deployment
To deploy using GitHub Pages:
1. Push your code to the `main` branch.
2. Go to your repository settings on GitHub.
3. Find the "Pages" section.
4. Set the source to the `main` branch and root folder.
5. Save and your site will be live at `https://<your-username>.github.io/<repo-name>/`.
